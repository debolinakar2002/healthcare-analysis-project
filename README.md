 # Healthcare Data Analysis Project

 # Overview
This project analyzes healthcare data to find insights about patients, diseases, and hospital stays.

# Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

# Key Insights
- Most common diseases: Arthritis, Diabetes, Hypertension
- Average hospital stay: ~15.5 days
- Most affected age group: 40–70 years
- Billing varies significantly across patients
- Gender distribution is balanced (50% male, 50% female)
